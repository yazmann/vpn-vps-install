# Безопасность

## Сообщить об уязвимости

Не публикуйте в Issues, Pull Requests или комментариях пароли, API-токены, IP-адреса серверов, домены, ссылки подписок и полный текст конфигурации.

Используйте **Private vulnerability reporting** в GitHub, если функция доступна. При отсутствии приватного канала создайте публичный Issue без технических деталей и укажите, что требуется приватная связь.

## Поддерживаемая версия

Поддерживаются последний стабильный релиз и актуальная версия ветки `main`.

## Что проверить перед отчётом

- используется чистый образ Ubuntu 22.04, 24.04 или 26.04 LTS;
- скрипт запускался от `root`;
- домен указывает на IPv4 VPS;
- в сообщении нет секретных данных.
